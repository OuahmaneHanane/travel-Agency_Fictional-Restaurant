# travel-Agency_Fictional-Restaurant
-Project Overview
This repository contains two responsive web pages built using Bootstrap 5, showcasing how to use the Bootstrap grid system and Bootstrap components effectively in real-world layouts.

 -Restaurant Website – Bootstrap & Grid System
A fictional restaurant landing page demonstrating the use of Bootstrap’s grid system to build a responsive and visually appealing layout.

- Features:
Header: Responsive navbar with branding and navigation links.

Hero Section: Full-width background image with centered heading and CTA button.

Menu Section: Grid layout with at least 3 food items, each including an image, description, and price.

About Us: Two-column layout with image and text.

Contact Section: Responsive form with name, email, and message fields.

Footer: Copyright and social media icons.

- Technologies:
HTML5

Bootstrap 5 (Grid system, utilities)

CSS (for minor customizations)

 -Travel Agency Landing Page – Bootstrap Components
A responsive travel agency website using Bootstrap components such as cards, accordion, and forms.

- Features:
Navbar: Agency logo and navigation links.

Hero Section: Scenic background image with heading, subheading, and CTA button.

Destinations: Bootstrap cards for showcasing 3+ destinations with "Learn More" buttons.

Tours Section: Accordion with tour package details.

Contact Form: Bootstrap-styled form fields.

Footer: Contains copyright and social.

- Technologies:
HTML5

Bootstrap 5 (Navbar, Cards, Accordion, Forms)

CSS (for additional style customizations)

- Responsive Design
Both pages are fully responsive and tested on different screen sizes using Bootstrap's responsive classes (container, row, col-*, etc.). The design adjusts smoothly from desktops to mobile devices.
